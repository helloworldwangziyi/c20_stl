# C++ 面向对象补课目录

这套笔记服务于当前 STL 学习路线，重点不是背概念，而是理解对象如何创建、使用、
复制、移动和销毁，并能把这些知识用到容器实现中。

## 章节

1. [类与对象基础](01_class_and_object.md)
2. [成员函数与类接口](02_member_functions.md)
3. [构造函数与对象初始化](03_constructors.md)
4. [析构函数与 RAII](04_destructors_and_raii.md)
5. [拷贝、移动与特殊成员函数](05_copy_and_move.md)
6. [继承](06_inheritance.md)
7. [运行时多态](07_runtime_polymorphism.md)
8. [编译期多态与泛型](08_static_polymorphism.md)
9. [面向对象设计原则](09_design_principles.md)
10. [配套练习任务书](10_exercises.md)

## 推荐顺序

先学第 1～5 章。当前写容器最依赖对象生命周期、初始化、RAII、拷贝和移动；
第 6～8 章再建立继承与多态的完整图景，最后用第 9～10 章做设计总结和练习。
